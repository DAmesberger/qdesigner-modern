# Codebase, requirements, ADR and ticket audit — 2026-09-11

> Historical snapshot: subsequent reconciliation is recorded in [the decision index](decisions/README.md). ADR 0039 removes JavaScript execution immediately; ADR 0040 retains PCA delivery. The findings below describe the pre-reconciliation snapshot.


The implementation is a substantial research platform, but it does not yet meet the complete September successor scope. The largest gaps are complete QDef exchange, Safe Logic and MCP, participant/group management, access policies, and legacy administrative/export workflows. GitHub captures most of that outstanding work. Requirements/status documents and the ADR register are not consistently current.

This is a source and tracker audit, with focused automated verification. It is not release acceptance, a full security audit, or physical timing certification. No implementation, existing documentation, GitHub issues, or remote branches were changed; this report is the only added file.

Sensors, synchronized physiology, intervention/training programs, push/technology-triggered EMA, external import formats and physical validation remain broader university requests or options/clarifications. They must not be silently counted as delivered, nor automatically added to the base implementation backlog. Native apps and SAML/SCIM Groups are explicitly excluded from base scope in the offer; SAML is honestly disabled in the product. The original PRD's broader promises such as WebXR, GraphQL, billing and laboratory-grade absolute precision also need an explicit retained/deferred/retired disposition rather than being treated as current release blockers by default.

**Delivered beyond the university baseline.** Relative to the university requirements as transcribed, the product adds CRDT collaboration and comments; OIDC/Zitadel and SCIM user provisioning; API keys, custom roles and domain administration; panel integrations/fraud checks; extensive psychometrics/CAT; and a much wider reaction paradigm library. These consume real product and maintenance scope, but are explicitly included in the September offer and/or accepted ADRs (0006, 0021, 0031, 0033). They are not demonstrated unauthorized scope creep. The strongest implementation outside the *new allowed behavior* is continued arbitrary authored JavaScript. The older duplicate designer shell is also retained code rather than a required product workflow, tracked in #40.

**ADR currency is mixed.** Sampled July decisions largely match the source: record-by-default timing validity, comments/series authorization, verified-domain SSO binding, and the honest eigenvalue/omega work. The register itself needs these corrections:

1. **Record the August/September architecture transition.** QDef's shared module, Safe Logic/no-JavaScript boundary and MCP decisions exist in newer prose/specs, but no numbered ADR reconciles them with ADR 0029's explicit JavaScript `onValidate` contract. Specify how existing questionnaires transition; do not misrepresent the QDef tracer as accepting executable JavaScript.
2. **Refresh the live authorization ledger.** `docs/decisions/0030-divergence-ledger.md:20` says the L3 project mutations are pending. `apps/server/src/api/projects.rs:477,633,983` already authorizes delete, membership changes and ownership transfer centrally. Other L14–L17 exceptions remain acknowledged unfinished work; do not declare the entire universal-entry-point migration complete.
3. **Disambiguate duplicate ADR 0024.** Both `0024-sqlx-offline-macros.md` and `0024-response-model-and-hardware.md` are accepted decisions. The similarly prefixed 0030 ledger is a working artifact, not another duplicate ADR.
4. **Repair lifecycle/navigation metadata.** ADR 0017 remains Proposed; Phase 7 remains Awaiting approval; Phase 8 says both in progress and all phases complete. `docs/agents/domain.md:8` lists decisions only through 0028 despite the sequence reaching 0036.
5. **Cross-reference superseded rationale.** ADR 0021 describes PCA's diagonal numerical stub; ADR 0036 replaced the numerical implementation while deliberately retaining the UI deferral. Preserve history, but make the current decision discoverable.
